## 💼 Featured Projects

### 🔄 Real-Time Order Event Pipeline
> Kafka-based event streaming for high-volume order lifecycle management across distributed services.

- Multi-topic Kafka architecture (`order-created`, `order-paid`, `order-shipped`) with idempotent producers, consumer groups, and **Avro schema validation**.
- Implemented **DLQ handling**, consumer lag monitoring, and automated retries — reduced processing failures by **~35%** in peak billing cycles.
- Spring Boot consumer persisting state transitions to PostgreSQL with **optimistic locking** to prevent race conditions.
- Sustained **~10K messages/sec** throughput under JMeter load with no consumer lag beyond SLA.

`Java` · `Spring Boot` · `Apache Kafka` · `Avro` · `PostgreSQL` · `Docker` · `JMeter`

---

### 🚦 Distributed Rate Limiter Service
> Token-bucket & sliding-window rate limiting with Redis-backed distributed state for production APIs.

- Configurable per-client, per-endpoint, and global throttling — deployed as shared service across multiple integration touchpoints.
- Redis atomic ops (`INCR` + `EXPIRE`) handling **5K+ concurrent clients** without race conditions.
- Prometheus-compatible metrics integrated with **Datadog dashboards** for real-time breach alerting.
- Achieved **sub-5ms p99 latency** — suitable for inline API gateway integration without impacting upstream SLA.

`Java` · `Spring Boot` · `Redis` · `Prometheus` · `Datadog` · `Docker`

---

### 🤖 AI-Powered Support Ticket Classifier
> LLM-based automation that triages and auto-resolves repetitive support tickets at scale.

- Integrated **LLM APIs** with a custom prompt engineering pipeline to classify by category, urgency, and resolvability.
- Reduced manual handling effort by **40%** and avg resolution time by **30%** — no headcount increase needed.
- Built a **feedback loop** where resolved tickets inform future classification prompts, continuously improving accuracy.
- Fallback logic escalates low-confidence responses to human agents — ensuring SLA compliance.

`Java` · `Spring Boot` · `LLM APIs` · `MySQL` · `Splunk` · `Datadog`
